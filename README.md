# ABAQUS-Plugins-TPMS-RVE-Generator
This Plugin(script) was written by python and can be used in ABAQUS to create RVE(Representative Volume Element), which contains TPMS(Triply Periodic Minimal Surface) structure. Users can choose or define different type of TPMS and set the mesh density and TPMS' thickness, and also can create new type of TPMS by adjust the equation of TPMS.
